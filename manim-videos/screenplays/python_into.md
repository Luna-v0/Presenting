# O que é python?
 

Visual: È uma linha do tempo em baixo com a data de 1991, com a foto do Guido na esquerda e o texto

Texto: É uma linguage de programação criada por Guido van Rossum (Paises baixos) em 1991, o foco da linguage era ser uma junção de bash com C que fosse mais legivel. O nome foi inspirado no Monty Python.
